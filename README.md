# 🤖 Agentic AI Lead Qualification System

## 📌 Problem Statement
Real estate companies receive a large number of leads but struggle to identify serious buyers.

## 💡 Solution
This project builds an Agentic AI system that:
- Analyzes incoming leads
- Scores their intent
- Recommends actions (Call / Follow-up / Ignore)

## ⚙️ Tech Stack
- Python
- Pandas
- Scikit-learn

## 🧠 How it Works
1. Load lead dataset
2. Apply AI agent logic
3. Predict conversion probability
4. Generate action recommendations

## 📊 Output
- High Priority Leads → Call immediately
- Medium Leads → Follow-up
- Low Leads → Ignore

## 🌍 Real World Use Case
This system can be used by real estate firms and channel partners to improve lead conversion efficiency.
